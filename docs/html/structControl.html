Detailed Description

Execution control options for the program.

These parameters determine whether assignments are generated, whether risk analysis is performed, and the output file name.

Parameters
GenerateAssignmentsAssignment generation mode (0 = run but do not report, 1 = primary domains only, 2 = primary reviewer vs primary+secondary submission).
RiskAnalysisRisk analysis mode (0 = none, 1 = single reviewer removal).
OutputFileNameName of the output file.
