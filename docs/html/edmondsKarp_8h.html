Computes the maximum flow in a graph using the Edmonds-Karp algorithm.

Edmonds-Karp uses BFS to find augmenting paths, guaranteeing polynomial time complexity. It repeatedly finds the shortest augmenting path from source to sink and augments flow along it until no augmenting path exists.

Parameters
gPointer to the flow graph. All edge flows are reset to zero before execution.
sourceIndex of the source vertex.
sinkIndex of the sink vertex.
Note
Complexity: O(V * E^2) where V is the number of vertices and E is the number of edges.
