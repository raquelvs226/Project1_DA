Parses a CSV input file and populates the problem data structures.

Reads the file section by section (#Submissions, #Reviewers, #Parameters, Control). Fields are comma-separated; everything after a '#' character on a data line is treated as a comment and ignored. The file must have the '.csv' extension and contain no duplicate submission or reviewer IDs.
