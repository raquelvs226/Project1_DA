Runs the full review assignment pipeline.

Orchestrates the complete workflow in order:

  1. Build the max-flow graph with buildGraph().
  2. Compute maximum flow with edmondsKarp().
  3. Extract assignments with extractAssignments() (if GenerateAssignments != 0).
  4. Perform risk analysis with getRiskyReviewers() (if RiskAnalysis == 1).
  5. Write results to file with writeOutputCSV().

In batch mode, outputPathOverride is used as the exact output path. In interactive menu mode, the path is derived from control.OutputFileName using a relative path convention.

Parameters
submissionsList of paper submissions.
reviewersList of available reviewers.
paramsProblem parameters.
controlExecution control options.
outputPathOverrideIf non-empty, overrides the output file path entirely (used in batch mode). Defaults to empty string.
Note
Complexity: O(R * V * E^2) where R is the number of reviewers (risk analysis iterations), V is the number of graph vertices, and E is the number of edges. Without risk analysis the complexity is O(V * E^2).
