Builds the max-flow network graph for the review assignment problem.

Constructs a directed flow graph with the following structure:

  • A single source node connected to each reviewer node with capacity MaxReviewsPerReviewer.
  • Each reviewer node connected to compatible submission nodes with capacity 1.
  • Each submission node connected to the sink with capacity MinReviewsPerSubmission.

Compatibility between a reviewer and a submission is determined by the GenerateAssignments mode in the Control struct.

Parameters

Returns
Pointer to the newly allocated Graph. Caller is responsible for deletion.
Note
Complexity: O(R * S) where R is the number of reviewers and S is the number of submissions.
