Determines the domain through which a reviewer matches a submission.

The matching rules depend on the GenerateAssignments mode in the Control struct:

  • Mode 0 or 1: Only primary reviewer expertise vs primary submission domain.
  • Mode 2: Primary reviewer expertise vs primary or secondary submission domain.
Parameters
rThe reviewer.
sThe submission.
controlExecution control options containing the assignment mode.
Returns
The matched domain ID if compatible, or -1 if there is no match.
