Extracts the list of reviewer-submission assignments from the flow graph.

Iterates over all reviewer nodes in the graph and collects edges with positive flow, mapping them back to the original submission and reviewer IDs.

Parameters
gPointer to the flow graph after running Edmonds-Karp.
submissionsList of all submissions.
reviewersList of all reviewers.
firstReviewerNodeGraph node index of the first reviewer.
firstSubmissionNodeGraph node index of the first submission.
Returns
Vector of Assignment structs representing the final assignment.
Note
Complexity: O(R * S) where R is the number of reviewers and S is the number of submissions.
