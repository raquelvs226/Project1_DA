Writes the assignment results and risk analysis output to a CSV file.

The output format depends on the control parameters:

  • If GenerateAssignments != 0: writes the submission-to-reviewer mapping (sorted by submission ID), the reviewer-to-submission mapping (sorted by reviewer ID), the total count, and any missing reviews.
  • If RiskAnalysis == 1: appends a risk analysis section listing the IDs of reviewers whose absence would make a full assignment impossible.
Parameters
filenamePath to the output file to be created or overwritten.
assignmentsList of reviewer-submission assignments to report.
riskyReviewersList of reviewer IDs identified as critical.
submissionsList of all submissions (used for missing review reporting).
reviewersList of all reviewers.
paramsProblem parameters (used to determine MinReviewsPerSubmission).
controlExecution control options (determines which sections to write).
Note
Complexity: O(A * log(A)) where A is the number of assignments, due to sorting.
