Determines the domain through which a reviewer matches a submission.

A reviewer is considered compatible with a submission according to the enabled matching rules in Parameters:

  • If PrimaryReviewerExpertise and PrimarySubmissionDomain are enabled, the reviewer's primary domain is compared with the submission's primary domain.
  • If PrimaryReviewerExpertise and SecondarySubmissionDomain are enabled, the reviewer's primary domain is compared with the submission's secondary domain when that secondary domain exists (s.secondary != -1).
Parameters
rThe reviewer being evaluated.
sThe submission being evaluated.
controlExecution control options.
paramsConfiguration parameters that define which matching rules are enabled.
Returns
The matched domain ID if the reviewer is compatible with the submission, or -1 if no valid match exists.
